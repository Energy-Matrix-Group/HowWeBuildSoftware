# How we build software

An interactive, plain-English guide to how Energy Matrix Group builds, checks and releases its app. It's written for the board and executives as well as developers, and styled to match the EMG brand.

Open `index.html` in any modern browser. It's a single self-contained file: the EMG logo, icons and scripts are inline, and the Montserrat font loads from Google Fonts (a system font is used if you're offline).

## What's inside

| Chapter | For |
| --- | --- |
| 01 The briefing: key numbers, the risks we manage and what stops them | Board and executives |
| 02 The guided tour: an animated build-and-release map with three stories | Everyone |
| 03–06 How it works: inside the app, the two copies, people and AI, the five safety checks | Everyone |
| 07 The developer playbook: branching model, commands and the rules every change follows | Developers |
| 08 The databases: interactive entity relationship diagrams and SQL scripts for EMG Company App Core and EMG Ticketing System | Developers |
| 09–10 Questions and glossary | Everyone |

Works in light and dark themes and on mobile, respects reduced-motion settings, and supports the keyboard (use ← and → to step through the tour).
